# Belvedere 1.1.0

First release distributed through the public Homebrew tap:

```sh
brew install --cask inquinity/tap/belvedere
```

- The About box — both the Apple-menu panel and **Settings → About** — says what
  Belvedere is and where it came from: a one-line description, the fork's network
  posture ("Belvedere never connects on its own. Remote content stays blocked
  until you allow it."), a link to `github.com/inquinity/belvedere`, and credit to
  the upstream project it was forked from.
- The version displays as **"Version 1.1.0"**, without a build number. The build
  number moves in lockstep with the version and never on its own, so it never
  distinguished two builds you could actually be holding. `CFBundleVersion` is
  unchanged in the bundle; it is simply no longer displayed.

Signed with Developer ID and notarized by Apple. Requires macOS 15 (Sequoia) or later.

## Note: 1.1.0 was published twice

The first 1.1.0 was replaced in place rather than superseded by a 1.1.1. Its notes
described the version as displaying "1.1.0 build 8", which the About box work then
changed; rather than ship a release whose only content was undoing the previous
one, the tag, the release asset and the cask checksum were all repointed at a
rebuilt 1.1.0.

**This is deliberate and it is the only time it happens.** Re-cutting a published
version is not something the process allows: it breaks anyone holding the earlier
artifact, since `brew upgrade` sees the same version number and does nothing. The
fix for an already-installed copy is to remove and reinstall it:

```sh
brew uninstall --cask belvedere && brew install --cask inquinity/tap/belvedere
```

From here versioning is strict: a published version is never rebuilt, and any
change to what a user sees ships under a new number.
