# Belvedere 1.1.0

First release distributed through the public Homebrew tap:

```sh
brew install --cask inquinity/tap/belvedere
```

- The version now displays as **"1.1.0 build 8"** in both the in-app and the
  Apple-menu About panels (previously "1.1.0 (8)").

Signed with Developer ID and notarized by Apple. Requires macOS 15 (Sequoia) or later.
